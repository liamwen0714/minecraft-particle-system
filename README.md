# minecraft-particle-system
Custom Minecraft particle effects built with Beet, Bolt, and Python.

## Features

- Custom particle animations
- Parametric equation-based effects
- Reusable datapack functions
- Beet and Bolt workflow automation
- Visual effects designed for Minecraft datapacks

## Technologies

- Minecraft Datapack
- Beet
- Bolt
- Python

## Example Effects

- Heart-shaped particle animation
- Spiral particle effects
- Dynamic visual patterns

## What I Learned

This project helped me understand datapack development, mathematical animation logic, and how tooling like Beet and Bolt can automate Minecraft function generation.
